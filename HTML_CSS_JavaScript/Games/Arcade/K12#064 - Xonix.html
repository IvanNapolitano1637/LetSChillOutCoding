XONIX

Conquista almeno il 75% del campo trasformando il mare in terra.

Sulla terra ti muovi con le frecce / WASD; entrando in mare lasci una scia gialla e il cursore avanza da solo: cambia direzione con le frecce (non puoi tornare indietro).

Quando ritorni sulla terra, le zone di mare chiuse dalla scia che non contengono palle diventano terra.

Muori se una palla bianca tocca la scia, se tocchi la tua scia, o se una palla nera (mangiaterra) ti raggiunge mentre sei sulla terra.
